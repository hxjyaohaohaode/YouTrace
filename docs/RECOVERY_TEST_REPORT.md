## 先红后绿的证据

修复后的本地检查由 `npm test`（前端目录）及 `npm run check`（server目录）执行：

- 独立账号数据库、不可在同一文档重绑定账号；保留源账号未确认修改
- 业务写入和outbox同事务；模拟quota失败两者同时回滚，界面不提前宣称成功
- HTTP400/401/403/409/413/429/500保留修改；持久冻结批次保证提交后丢响应的相同请求重放
- 源快照校验避免旧界面内容借用新的远端版本覆盖；只有已确认的前序变更可以推进后续本地修改的baseVersion
- 模拟两个运行时：迟到ACK不能清掉后续批次；旧pull不能回退游标或冲突证据
- 持久清理世代阻止另一标签页清理前的pull重新灌回数据；习惯被删时仍保留未确认子打卡，直到显式比较处理

- 速记确认稿保留编辑后的内容；全实体写入和确认收据同事务；重试不重复新增；日记追加而非覆盖

## 真实浏览器验收

## 用户结果

从首页发现目标，为自己的计划建立两条同名但描述/类型/领域/日期可辨的记录。只调整所选那一条的手动进度0→25→100→25，完成不是不可逆归档，也不由习惯/AI推断。读清卡片、进度条、完成数和平均值；筛选后要知道统计的是全部目标还是当前显示项。

编辑具体描述/类型/优先级/计划日期，取消不改原记录和版本；设置后清空可选日期应对应云端null及界面不再显示。实际保存必须保留同ID、原进度及同名邻居。遇到存储不足，读得懂尚未保存还是已保存但显示未刷新，输入有退路；实际操作恢复后核对服务器和队列。删除的取消、失败、真实重试和重载结果分别取证。

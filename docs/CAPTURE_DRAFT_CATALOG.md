# 本机确认稿只读目录：最小服务候选

基线：公开 `484774761289f70b32c289fe616e2c736987d74b`。原需求与缺口见 `CAPTURE_RETURN_TASK_BASELINE.md:167–171`。本轮只补目录资格服务，不接页面、路由或按钮；普通用户可见找回流程仍未交付。旧稿存在不等于用户可以找到它。

## 资格与保全

`listCaptureDraftPage` 在任何 await 前取得实际已验证的 owner、当前数据库对象、会话 revision 和内存 generation；每页读取 epoch，并在事务内及交付前再次验证。未登录、不同 owner、换号、同 owner 重新登录、epoch 变化和读取失败均拒绝，不伪装为空目录。

只扫描当前账号物理库的 `capture-review:` 主键区间；每项须 key 与原 ID 精确相等、明确具有相同 owner/dataEpoch、当前已知字段与类型、原 authenticated 会话标记。旧会话 revision 可以不同，但只供预览，绝不重绑定为当前会话。当前实现对未清除的新库采用既有 `initial` epoch 语义：只有实际 epoch 行缺席且稿中明确写着 `dataEpoch: initial` 才匹配；缺失稿件 epoch 不补造，已存在但缺 value、undefined/null/非字符串、空值/超长或扩展字段的损坏 epoch 行均拒绝；首读、事务末和交付前使用同一严格校验。它不是导入任意旧稿的兼容承诺。

任何同 ID `capture-applied:`、`capture-source:` 或 quickNotes 行存在，都阻止作为未提交稿返回，包括损坏或 undefined 的提交标记。未知归属、不同 epoch、缺字段/未知字段、坏 schema、稀疏/重复候选 ID 和超出声明范围的稿都跳过且完整保留，只给本页总 skipped 计数，不暴露被排除项的原文/ID/归属。不会调用 `loadCaptureDraft`、解析、创建稿、保存、认领、上传或写当前 input/review 指针。

返回 detached 原始字段副本，不裁剪文字、不重算日期、不改候选选项。已知未完成编辑值（例如空名称、0金额、未确认日期）可以保真列出；目录资格不是业务提交有效性。各字符串/候选数量边界明确限制当前支持范围：原文5000、日记及排除文字10000、每类候选100、ID256、金额文本512；超出者继续保留，不自动截断或修复。旧扩展字段不静默丢弃后列出。

## 有界分页与一致性

- 默认每页扫描20个候选 key，调用方只能指定1–50；另读至多1个 lookahead 判断是否还有候选。
- 不合格行也推进游标。因此前50条都不合格时可返回空 entries + 非空 nextCursor，不能将它显示为“没有任何旧稿”。不返回无法证明的目录总数。
- 游标是不含原文的内存不透明对象，绑定 owner/物理DB/session/generation/epoch；不能序列化后伪造或跨登录使用。刷新/重载从第一页重新开始，不持久写游标。
- 每页用 settings + quickNotes 单个 readonly 事务同时核稿件与提交标记。交付前额外 readonly epoch 检查。不宣称跨多页是同一个封存快照：并发新建且 key 排在已有游标前的稿需从头刷新才能看到；继续核对前未来 UI 必须重新读取资格，不能拿目录预览作为保存能力。
- 顺序仅是实际 IDB 主键顺序，不称最近修改/创建时间。capturedAt 是原文时间依据，不伪造更新历史。
- 有界的是 key 数/已支持返回形状；底层损坏的单个超大 IndexedDB value 仍可能在读取时占内存。本服务不声称防止浏览器 OOM，不生成截断备份。

## 本地证据与未验部分

基线红合同用真实生产 create/save 模块及 fake-indexeddb 生成 O/R/D，确认当前模块缺少只读目录能力。它是明确缺实现的合同红，不是源稿删除报告。曾尝试直接跨 owner bind 的测试准备被现有“必须 reload”保护正确拒绝；另一次 native transaction 观察器晚于 Dexie 绑定导致无事件，已按真实缓存机制修订并保留原日志。

新增18项真实服务 + fake-indexeddb 合同覆盖 O/R/D 精确原文/全表保全、边界与坏值、已提交排除、124候选/3页穿过55个不合格前缀、真实 readonly 模式、读取/事务 abort 失败、旧结果晚交付后的 epoch/重新登录拒绝、被绑定文档 owner 不匹配拒绝与另一账号独立库不变、游标伪造/范围、脱离引用、无网络及每页快照语义。邻接既有15项确认稿事务/幂等合同另跑，共33项通过。

这里没有浏览器/UI验收，没有以同一 document 强行切数据库冒充真实 A/B/A 重载，没有自动恢复任何未知旧稿。此前 fcec 初始化队列根因仍未知；本服务不改变原12秒、初始化或其他业务行为。全套门禁、独立审查、原生入口和发布状态各按后续精确回执，不由本合同自动授予。

独立审查在首版候选复现 epoch 行存在但 value 缺失/undefined 被当缺席的P2；原基线和实际红日志保留。修订只在目录服务区分行存在性，补初读7种坏值和迟到缺席→损坏5种矩阵，拒绝时全表精确保留，不修改全局actor或修复原库。

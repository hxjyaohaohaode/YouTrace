## 共享同步账号隔离修复

新的独立合成整链发现基线P0：A账号事务已提交但回调迟到，切到B后，旧flush可将A队列上传到B并消费ACK；相反，B的pull也可能写入仍绑定的A库。这是实际前端模块、认证中间件、Hono和隔离SQLite复现，不是生产泄露声明。

候选同步将push、pull、定时器和重试绑定到精确DB对象、已验证owner、会话generation/revision、本机clear epoch及同步代次。请求在末次权限/epoch检查旁启动；网络等待不占IDB事务。批次准备、ACK、失败元数据、远端记录/游标和显式重试，在事务最后重新检查，失去权限则回滚，不清掉旧队列或冻结请求。

保留原冻结payload、幂等mutationId、后继baseVersion、单飞唤醒和退避。旧会话的迟到401/账号不匹配响应仍失败，但不得撤销后来登录的会话。该API副作用测试刻意控制响应交付，不能称为原生fetch取消竞态已经发生。

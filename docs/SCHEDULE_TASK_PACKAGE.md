## 旧JS与本机数据保全

简单升级Dexie版本无法阻止旧JS打开同库并ACK丢字段的冻结请求。因此新账号存储使用独立物理generation，按刚验证的账号复制原账号库。全部物理表、原key、未知字段/表、outbox顺序/自增高水位、冻结批次和设置保留；共享`youtrace`与guest绝不自动认领。

完整复制、校验和activation有持久记录；失败保留原库且不进入空库。clear保留cutover记录，重开不能复拷原数据。旧窗口后来修改仍在原库，设置提供状态检查和单独导出；不自动合并或上传。旧JS仍可能自己联网发送其旧队列，用户须关闭旧版窗口；服务端版本/例外门禁是另一层保护。

备份v3的`tables`是JSON阅读视图；`rawTables`才是带类型、原key和引用关系的精确保留表示。单独的generationRecovery标明升级时基线与当前旧来源。当前没有承诺一键自动恢复所有未知结构；下载、保留原库与恢复工具是不同验收项。

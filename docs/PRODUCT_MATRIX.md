# 有迹 × 群响：产品边界与互通路线

状态：边界已用于实现取舍；跨产品互通 **Planned**，没有运行中的共享登录或双向同步。

有迹独立管理个人生活记录、意图、日程、习惯、消费与反思。工作预约、成人学习也可以是生活资料；不按“工作/生活”机械排他分割。

群响独立围绕AI参与的目标、过程、成果和验收，涵盖社交、工作、创作、学习与娱乐。两者可各自拥有目标、任务、日历与对话，但有迹自报进度不能自动满足群响成果验收。

未来最小互通是用户选定字段的一次性确认稿：有迹选定目标与约束→群响研究或产出；群响选定已接受的下一行动/期限→有迹待办或日程。必须展示目的、字段、来源修订号和目标账号/空间，明确确认后执行。

协议至少需要schemaVersion、handoffId、sourceId/revision、selectedFields、destination、expiresAt、幂等请求摘要、目标版本冲突与应用收据。重复确认不得重复创建；源修改/撤销/删除需可见处理。每个提醒只有一个负责方。

禁止相同手机号推定同一身份、共享数据库/凭据、自动传日记/情绪/消费或敏感URL参数。已导出副本无法承诺远端彻底擦除。日期必须区分全天日期与时刻并保留时区；金额必须声明币种与最小单位。

当前优先修复各自数据闭环，不放置只会跳转却宣称已互通的按钮。上线前需重复确认、错账号、并发编辑、失效授权、离线重试、部分失败及删除生命周期测试。

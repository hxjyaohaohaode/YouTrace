# Capture 目录详情转换的正向 Tab 保护（候选）

基线公开2f51ba85a391373ac0d9f09af1c5148e0052020c。已完成同ID交接的两宽pointer链与本候选分开；本项只补原Modal详情转换的键盘边界，不新增产品功能、业务写入或隔离页面全局Esc。

## 可达源级红与最小修订

真实QuickNote/QuickNoteResult、Catalog、Modal、Button和Checkbox与真实服务/fake-indexeddb运行：点击目录里的查看按钮后，React详情替换确实卸载原聚焦按钮。DOM形状宿主明确将activeElement置body以模拟平台移除焦点；原Modal正向Tab仅处理最后控件，未兜回面板外焦点，两个父组件合同均红。另直接执行原Modal effect合同1红。它们证明源级可达模型缺口，不证明旧版浏览器移除焦点时序或实际逃逸已被原生复现。

唯一生产改动将正向Tab条件对称扩展为“在最后控件或面板外”。仍只由最上层Modal接管；内部Tab交还浏览器，不相关键不拦截，Esc沿原onClose，清理监听与原触发者回焦逻辑不改。无焦点控件时原拦截不变。所有归属、typed CAS、提交证明、队列及同步逻辑未改。

## 本地合同范围

实际父组件/原Modal验证：两父详情替换后的Tab兜回、Esc关闭和原入口回焦、原表/双指针精确保全；隔离核对标题与安全返回；正在保存时头尾返回、重复保存和旧编辑回调无效，Escape不意外关闭或第二次提交；嵌套最上层归属、内部Tab、非Tab、空面板、监听清理。焦点目标和DOM查询是明确替身，不授几何、滚动或浏览器默认Enter/Space行为。

## 仅既有首个只读窗口的原生补测

复用capture-return两宽、既有25任务集合和原预算。首个目录窗口先保留原来的两份完整原稿/字段核对，再通过“返回目录”和原查看按钮重新进入最后一份详情。记录原按钮确实断开、按键前activeElement，再只按一次真实Tab；要求焦点位于同一已核详情Modal、连接且可用，既有严格geometry证实全控件可见且未被覆盖，非透明outline作为必要门槛，原PNG另做人工核对。随后真实Escape自然回原入口；全表、keys、GET账、原表单/URL/双指针仍精确相等，native写尝试0，原观察器还原。可信按键账必须恰为Tab、Escape。

不使用JS focus/scroll、force点击或放宽原7000ms。详情阅读仍可采用原有真实滚轮；在新Tab后的焦点判定内不允许滚动救援。失败按原链独立保存首错、编辑、写账、源库、GET和截图；收集失败明确记录，不覆盖原错。

此步骤不验证完整Save键盘链、不授WCAG/读屏认证，也不解释fcec未知初始化异常。新精确SHA原生尚未执行；本地/脚本存在不能写原生通过。

## 原生录入与真实分组

实际登录/引导 → 首页正常侧栏或手机“全部功能”入口 → 待办“新建待办”。真实键盘、原生 select 与日期分段输入录入五条短标题：

1. 合成：归还图书，2026-10-06，高，逾期
2. 合成：归还图书，2026-10-07，低，今天
3. 合成：周末整理书架，2026-10-11，中，本周
4. 合成：下周寄明信片，2026-10-12，高，更晚
5. 合成：整理抽屉，无截止日期，低，更晚

这是浏览器合成周三的自然周，周日属于本周，下周一不属于。没有假设 Todo 存在“今天/全部”筛选按钮。五条全部从真实界面创建，输入与实际持久草稿 ID 先冻结再保存；不注入业务记录或制造其他 metadata。相同标题必须先由可读日期和优先级区分，隐藏 ID 仅在选中真实行之后旁证。每个分组检查点重新读五条记录的实际组归属，不能只凭总数正确；并读取真实“逾期/今天/本周/更晚/已完成”标签及数量。

创建前先保留完整原来源；输入仅允许该精确 `record-draft:todo:new` 值与 revision 写入。保存后同 ID、声明业务字段、空 outbox、无冲突、精确正整数版本等于最终 Todo event，旧全实体账本前缀及所有旧行/字段/版本保全，只增加一个 Todo event。最后仍用最初冻结的记录集合核验，不能拿后来变化的结果倒推输入。

## 完成、跨视图找回与真正撤销完成

通过昨天到期的真实行复选框完成任务；等待该已核身份行实际呈现选中且可操作后读取来源，避免把异步写入开始前的旧空队列当 ACK。新增本机 completedAt 必须位于真实点击前/提交后的浏览器 Date 观察窗口，服务端原始时间字符串须对应相同 instant；同 ID、除 done/completedAt 外的全部本机字段、邻居和旧历史保留。

正常导航进 Timeline，单次点“全部记录”后等待实际 URL 的 `range=all` 及唯一选中按钮，再冻结起点。再单次切“近7天”，同样等待实际 `range=7` 与唯一选中态。两种视图都实际阅读同一完成事件、标题、完成说明、时间和 `2026-10-07` 分组标题，不能把 `2026-10-06` 截止日当完成日。只有这个任务今天的真实完成记录；这些操作证明范围选择、同 ID 找回与返回保持，不授历史七天边界过滤通过，也不制造旧完成时间。

点击真实 Timeline 记录进入原 Todo 编辑器，核 actual URL 同 ID 和全部当前字段，取消后点“← 返回时间线”，确认原 `range=7`、唯一选中态及当前事件仍在。进入该导航/阅读/取消链前后的完整来源和历史保持不变。

经正常导航回 Todo，阅读真实“已修改完成状态”提示，点击现有“撤销上次完成状态”。要求原 ID 全部本机源事实恢复为完成前的完整对象，服务端除合法 updatedAt 外也恢复；新版本和一条 upsert 事件可前进，原完成 event 留在账本。重新核全部五行组归属，再去 Timeline“全部记录”，实际等待已加载且无错误的空态并核没有完成待办事件，随后回 Todo 找回原逾期行。这里是真正完成状态撤销，队列仅在当前内存会话；不宣称 reload 后可撤销，也不是删除撤销。

## 证据表达与检查

每个关键源转移保存 `todos`、`settings`、`outbox` 三表完整 readonly 样本，GET `/todos` 当前服务端全行，以及从 cursor 0 分页获取的完整 GET `/sync/pull` 全实体账本。服务端行必须与账本重建逐字段相同；不是只比较业务字段或 Todo 子账。三表样本不是全库备份。

本机常见 Todo 没有 createdAt/updatedAt；本包不添加或推断这两个字段，也不要求它们非空。已存在字段与 absent/own-undefined 差异均保全：本机 own-undefined dueDate 采用明确类型标签，服务端空日期仍是原始 null；数字本机 completedAt 与服务端时间字符串单独留存。Date、BigInt、特殊数字、Map/Set 沿用快照类型约定；marker 冲突、稀疏/扩展数组或未知对象类型停止采样，不声称任意历史 structured-clone 数据都支持。原生没有种入 unknown 字段，纯反例才用于检验丢字段误绿风险。

浏览器 Date 使用现有以 `2026-10-07T04:00:00.000Z` 为锚继续推进的 clock；计时器、performance、Cookie 和 Node/server Date 均保持真实。工件保留浏览器合成时间、driver 实际观察时间和服务端原始审计时间，不强行统一。

每次指针只有原几何验证后的真实 mouse click；输入用键盘，滚动用真实 mouse wheel。没有 DOM click/value 赋值、造 change 事件、业务 HTTP 写入或隐藏路由。短标题需真实 input 宽度足够且无内部横滚；可达控件与完整 DOM value 不能当长值完整可读证明。行身份、实际组、全字段编辑器、Timeline 条目及原错误都有截图和只读取证。首败保存原图与可获得的原来源，立即停止依赖动作；cleanup 失败另记而不替换首败。

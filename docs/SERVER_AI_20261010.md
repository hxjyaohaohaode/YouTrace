# 可选部署者基础文字聊天（本地候选）

默认关闭、无预置模型、无内置 API 密钥。未配齐或配置无效时此能力不可选，基本增删改查和规则回复不依赖它；账号自配 BYOK 保持独立。旧 `LLM_*` 不读取。代码准备不代表真实供应商验证、开通或部署。

## 部署者显式配置

仅服务端：`SERVER_AI_ENABLED=true`，`SERVER_AI_API_KEY`，`SERVER_AI_BASE_URL`，`SERVER_AI_MODEL`。模板后三项均为空，没有自动生成或读取真实密钥。不能把任何 key 放入 `VITE_*` 或前端构建配置。

允许的基础地址是精确白名单，不允许用户请求带 URL、请求头或重定向：

- 千问北京：`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型标识须属 `qwen` 家族。
- DeepSeek：`https://api.deepseek.com` 或 `https://api.deepseek.com/v1`，模型标识须以 `deepseek-` 开头。
- 小米 MiMo：`https://api.xiaomimimo.com/v1`，模型标识须以 `mimo-` 开头。

这些是国内厂商官方接口限制，不等于对所有供应商的数据驻留做保证。白名单不含海外 OpenAI/Anthropic；千问也不允许在本站基础配置中选国外模型家族。账号既有 BYOK 数据不修改。智谱仍保留原账号 BYOK 模板，此基础低成本路径暂未加入。

模型版本和价格随供应商变化，操作者填入自己账号实际可用、预算允许的当前型号。家族校验不证明某具体型号存在、已开通或始终低价；不会自动换型号。先在供应商设置硬预算/额度上限。此候选未发送任何真实模型请求，没有验证余额或实际计费。

## 选择、隐私和成本边界

教练页默认仍用规则；必须明确勾选显示的模型与 HTTPS 接收端，同意发送本次文字及当前会话有限历史。最多20条已标记文字、12000历史字符，不附加日记/账单/目标/任务等应用记录。BYOK与站点来源互斥；BYOK故障不会静默换站点密钥。账号切换、重新打开页面、服务器重启或配置变化后需要重新选择；地址、模型、密钥改变使旧选择失效。

站点回复只显示文字，不解析模型生成的工具/操作建议；现有本地规则的手动导航建议不变。真实响应不伪造；失败时明确标记规则回复，不重试或切其他供应商。

防滥用采用单进程保守上限：站点并发2、每小时固定窗口60次、每账号每分钟20次，独立计数不被普通IP/短信限流桶挤出。失败尝试也计数。重启会重置预算，多实例不共享此计数；此版本仅单实例，不把该软限制当供应商硬金额预算。

站点专用请求禁用思考：千问 `enable_thinking:false`，MiMo/DeepSeek `thinking:{type:'disabled'}`。千问/MiMo仅传 `max_completion_tokens:1024`，DeepSeek仅传 `max_tokens:1024`。不修改 BYOK 的原有请求语义。统一30秒墙钟、256000响应字节、16000显示字符上限；取消、异常和结束释放并发。API key不进提示词、不返回客户端，跨流片段回显检测拦截明文密钥。

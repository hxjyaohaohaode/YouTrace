# 账户自配 AI（2026-10-10 候选）

## 实际变化

应用不预置模型、不内置服务商密钥，也不再读取 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。旧部署环境中残留这些变量不会启用新版本的模型路径。删除代码配置不会撤销服务商平台上的旧密钥，历史公开凭据仍需在对应服务商处撤销。

每个账户可在设置中添加一条自己的连接，选择官方接口、填写本人账户实际可用的模型标识和 API 密钥。服务商选择项是添加表单模板，不是已安装模型；模型输入没有默认值。当前仅支持 DeepSeek、智谱 GLM、千问北京接口和小米 MiMo 的文本 Chat Completions。没有声称任一账号已开通、具有额度或支持任一具体模型。

连接支持读取非敏感元数据、添加、修改、删除和单次明确确认的连通测试。保存不会自动测试。更换服务商必须重新输入密钥，并重新确认对话外发许可。调用使用本人账号额度，测试和正式对话都可能收费；没有自动重试或跨服务商降级。

## 对话范围

设置页明确展示接收地址、外发范围和费用归属；教练页每次打开默认不勾选个人模型，用户另行选择后才会走外部模型路径。发送内容限当前输入和当前会话中最多 20 条、合计最多 12,000 字符的可发送历史。历史来源为新建用户文字或本人模型回答；旧来源不明、规则回复和安全模板均不外发。不会自动附加日记、账单、习惯、目标、日程或其他应用资料。

未配置或未选择模型时使用明确标注的本地规则回复，不能将其算作大模型调用。模型中断后的本地回复同样标记来源。原有聊天内容、业务记录、品牌资源不被删除；迁移给历史消息标记 `legacy`，不改写正文。

## 安全与运维合同

- 配置按已认证账户隔离；连接独立 UUID 和版本共同防止跨账户、旧窗口、并发修改及删除后重建的旧授权复用。
- API 密钥仅短暂保留在表单内存，未进入浏览器持久存储、同步队列或普通账号导出。服务器用 AES-256-GCM 加密，认证附加数据绑定账户和服务商。API 不返回密钥或密文；错误只返回固定安全代码。
- 部署者须单独配置 `AI_CREDENTIAL_ENCRYPTION_KEY`，值为独立 32 字节密钥的标准 Base64。示例保持空白，本候选没有生成或配置生产密钥。缺失或无效时保存和使用凭据失败关闭，页面明确提示。
- 完整 SQLite 备份含加密凭据；恢复必须同时取得原匹配加密密钥。加密密钥不得放入数据库、Git、公开包或普通账户导出。不要随意更换此密钥；错误密钥无法解密旧连接，不会自动重建覆盖。
- 目的地址是代码内固定的精确 HTTPS URL，不接受自定义地址、请求头或重定向。请求有并发、频率、上下文和超时限制；响应硬限 256 KB、输出 16,000 字符，并防止完整密钥跨流分块被回显。
- 客户端断开、连接修改/删除、整账号删除会取消当前进程的相关在途请求。取消注册表是进程内机制；不能保证跨进程撤回，也不能撤销已发送请求或既有计费。当前部署仍按既有单进程 SQLite 约束运行。
- 新迁移使用事务；失败回滚不留下半创建的连接表。没有运行生产迁移或删除真实数据。

## 验证边界

本地检查使用隔离合成数据库、明确标注的测试凭据及 fetch 替身。没有真实服务商调用，没有费用消耗，没有生产配置变更。

已覆盖：空账号/残留共享环境变量、密文不回显、owner/版本/重建隔离、并发写入、新供应商须新密钥、明确对话同意、无业务上下文泄漏、历史来源过滤与字符限额、测试请求单独确认、分块密钥回显拦截、响应超限、异常不重试、连接和账号删除取消在途流、非空迁移及失败回滚。React 宿主测试覆盖表单空态、密钥不进导出/本地存储、重复保存、账号变化与迟到返回、换服务商清除许可及单独测试/删除确认。

真实浏览器验收尚未在当前执行环境通过。已为正常 CI 的既有原生浏览器链增加添加/删除、自有模型逐页选择与零供应商请求的场景；仅有场景代码不代表验收通过。生产发布仍需备份/恢复门禁、加密配置、精确提交的 CI 和新界面工件验证。
